Benchmark overview

One Environment. Four Planner Capabilities.

Mobile planning requires a central agent to coordinate tools, persistent user context, reusable procedures, and specialized sub-agents while adapting to execution feedback. MobilePA-Bench evaluates these abilities through 1,705 distinct queries, eight descriptive query domains, and 212 mobile tools in a shared stateful simulated environment. Its unified protocol covers Tool Use, Memory Usage, Skill Usage, and Sub-agent Collaboration. Each query receives a fixed Tool Call, State Change, or Agent Behavior checker, while capability gates enforce applicable memory and skill-routing requirements. This separates successful task completion from compliance with prescribed resource and procedural requirements, exposing failure stages that aggregate success alone cannot diagnose.

Tool UseSelect and ground executable mobile APIs. Memory UsageRetrieve persistent context and act on it. Skill UsageFollow reusable procedures under SOR and MTSR. Sub-agent CollaborationDelegate and integrate specialized execution.

Evaluation Protocol

Non-Skill tasks expose 15 candidate tools. Skill-Only Routing exposes 20 candidate skills without direct business tools; Mixed Tool-Skill Routing exposes 15 direct tools plus five candidate skills. Every trajectory runs for at most 15 steps. Missing or invalid predictions count as failures, and API-judged outcomes require a unanimous decision from two fixed judges.
